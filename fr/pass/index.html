Comment ça marche ?

  1. Remplissez le formulaire ci-dessous (nom, téléphone WhatsApp et e-mail) : votre code de commande s'affiche tout de suite.
  2. Payez 7 DT par D17 ou IZI au 24 321 390, avec ce code pour motif du paiement, et envoyez la preuve par WhatsApp (bouton vert : le message contient déjà le code).
  3. Votre code de commande s'ouvre dès réception du paiement. Le Pass dure 24 heures à partir de ce moment.
  4. Revenez sur cette page : le code s'active tout seul sur ce téléphone (ou tapez-le dans « J'ai un code », ou sur la page du document) : tous les documents se téléchargent.

Demander mon Pass Journée

Votre nom, votre téléphone et votre e-mail servent seulement à reconnaître votre paiement et à vous envoyer votre code : ils ne sont jamais publiés ni vendus (envoi par le service Formspree). Rien n'est envoyé sans clic sur « Envoyer ma demande ».
